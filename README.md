## 🏆 Featured Project: SellerSquare
A multi-app e-commerce platform modelled on Amazon and Flipkart.

| App | Purpose |
|---|---|
| `sellersquare-user` | Customer storefront: mega-menu, Deal of the Day, product rails, cart and wishlist |
| `sellersquare-seller` | Seller dashboard |
| `sellersquare-admin` | Admin panel |
| `sellersquare-backend` | API and authentication |

**Highlights:** server-rendered category pages with shareable filter URLs, token-based auth, shared cart/wishlist context, clean server/client component split.
